# C5 — Torneo de algoritmos de ordenamiento

Comparé Insertion Sort, MergeSort y QuickSort en arreglos de 559, 1.118, 2.236 y 4.472 elementos. Los datos se generan con una semilla fija para que sean reproducibles.

El protocolo calienta cada algoritmo para cada tamaño, realiza tres corridas medidas y calcula el promedio. Cada corrida promedia 30 ordenamientos de copias independientes; la creación de copias queda fuera del cronómetro. Cada resultado se valida para comprobar que los valores estén en orden ascendente.

- torneo.js: implementación completa.
- resultados_c5.csv: tiempos de cada corrida y promedios.
- informe_conclusiones.md: tabla comparativa y conclusiones del torneo.

Los tiempos corresponden al entorno indicado en el informe y pueden variar según el equipo. Los arreglos numéricos son datos sintéticos de prueba asociados al volumen del caso de matriculación.
